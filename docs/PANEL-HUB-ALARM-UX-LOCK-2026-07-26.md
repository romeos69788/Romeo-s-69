# Panel hub — συναγερμοί / βλάβες ανά τομέα

**ΚΛΕΙΔΩΜΕΝΟ** · 2026-07-26 · ρητή εντολή χρήστη («ταιριάζει απόλυτα · κλείδωσέ το»)

**Οθόνη:** Viewe 7″ panel λεβητοστασίου (hub V4) · όχι θερμοστάτης χώρου

---

## Αρχή

Κάθε ένα από τα **6 πλαίσια** (ΝΕΡΟ · ΑΝΤΛΙΑ · ΕΞΟΔΟΙ · ΜΠΟΙΛΕΡ · ΣΥΣΤΗΜΑ · ΔΙΚΤΥΟ) έχει τον **ίδιο** μηχανισμό συναγερμού:

1. Βλάβη στον τομέα → ένδειξη στο **πλαίσιο hub**
2. Κάτω μπάρα + **ηχητικός** συναγερμός
3. Mute από την κάτω μπάρα
4. Μέσα στη detail οθόνη → κόκκινο στο **συγκεκριμένο** στοιχείο (π.χ. ένας αισθητήρας)

---

## Ροή (παράδειγμα: αισθητήρας νερού)

| Βήμα | Συμπεριφορά |
|------|-------------|
| **1. Εμφάνιση βλάβης** | Το πλαίσιο **ΝΕΡΟ** παίρνει ελαφρύ **διαφανές κόκκινο** που **αναβοσβήνει**. |
| **2. Κάτω μπάρα** | Σταματούν τα idle μηνύματα (αντλία ΟΝ, ΟΚ, κ.λπ.). Εμφανίζεται μήνυμα τομέα, π.χ. **«Πρόβλημα στο νερό»**. Η μπάρα/κουμπί συναγερμού γίνεται επίσης ελαφρύ διαφανές κόκκινο και αναβοσβήνει, **συγχρονισμένα** με τον ηχητικό. |
| **3. Πάτημα κάτω μπάρας (mute)** | Σταματάει ο **ηχητικός** συναγερμός. Φεύγει το κόκκινο / αναβοσβήσιμο της **μπάρας**. |
| **4. Μετά το mute** | Το πλαίσιο τομέα (**ΝΕΡΟ**) **παραμένει** κόκκινο αναβοσβήνον όσο υπάρχει ενεργή βλάβη — ώστε να μην χαθεί η ένδειξη μετά τη σίγαση. Η μπάρα μπορεί να δείχνει ήπιο κείμενο τύπου «Πρόβλημα νερού — σε σίγαση» (ακριβές διατύπωση στο firmware). |
| **5. Detail οθόνη** | Πάτημα ΝΕΡΟ → οθόνη θερμοκρασιών νερού. Ο αισθητήρας που δεν δίνει πληροφορία (π.χ. προσαγωγή ενδοδαπέδιας) έχει το **ίδιο** ελαφρύ διαφανές κόκκινο στο δικό του slot. |
| **6. Αποκατάσταση** | Όταν ο επεξεργαστής ξαναπαίρνει έγκυρα δεδομένα από τον αισθητήρα → φεύγει το κόκκινο του slot · αν δεν μένει άλλη βλάβη στον τομέα → φεύγει και το κόκκινο του πλαισίου hub. |

Το ίδιο μοτίβο ισχύει για **ΑΝΤΛΙΑ · ΕΞΟΔΟΙ · ΜΠΟΙΛΕΡ · ΣΥΣΤΗΜΑ · ΔΙΚΤΥΟ**.

---

## Πολλές βλάβες μαζί

- Πολλά πλαίσια μπορούν να αναβοσβήνουν κόκκινα ταυτόχρονα.
- Κάτω μπάρα: είτε το **σοβαρότερο** μήνυμα, είτε εναλλαγή μηνυμάτων τομέα (επιλογή υλοποίησης · όχι αλλαγή αρχής).
- Mute σιγάζει τον ήχο / κόκκινο μπάρας για τον τρέχοντα κύκλο συναγερμού· τα πλαίσια μένουν κόκκινα μέχρι αποκατάσταση.

---

## Ρόλος οθόνης ΣΥΣΤΗΜΑ

- **ΣΥΣΤΗΜΑ** = βλάβες / υγεία **γενικής** φύσης (όχι διπλότυπο probes νερού ή λίστας ρελέ).
- Βλάβες αισθητήρων νερού → ένδειξη στο πλαίσιο **ΝΕΡΟ** + detail ΝΕΡΟ.
- Βλάβες HP / εξόδων / μπόιλερ / δικτύου → αντίστοιχα πλαίσια.
- Σύνοψη «κατάσταση εγκατάστασης» μπορεί να ζει στο ΣΥΣΤΗΜΑ χωρίς να αντικαθιστά τα παραπάνω.

---

## Οπτικοί κανόνες (κλειδωμένοι)

| Στοιχείο | Εμφάνιση |
|----------|----------|
| Πλαίσιο hub με βλάβη | Ελαφρύ **διαφανές κόκκινο** + **αναβοσβήσιμο** |
| Κάτω μπάρα σε ενεργό συναγερμό (πριν mute) | Ίδιο κόκκινο αναβοσβήσιμο + μήνυμα τομέα · **χωρίς** idle ticker |
| Κάτω μπάρα μετά mute | Χωρίς κόκκινο αναβοσβήσιμο · χωρίς ήχο · ήπιο κείμενο σίγασης OK |
| Slot μέσα σε detail | Ίδιο κόκκινο στο **ελαττωματικό** στοιχείο μόνο |

---

## Idle κάτω μπάρα (χωρίς βλάβη)

Παραμένει ο υπάρχων ticker κατάστασης (ΟΚ / ΟΝ ανά τομέα) — **μόνο** όταν δεν υπάρχει ενεργός (μη-muted ή προς εμφάνιση) συναγερμός που απαιτεί μήνυμα βλάβης. Με ενεργή βλάβη πριν το mute: ticker off · μήνυμα προβλήματος on.

---

## Υλοποίηση (αργότερα · όχι μέρος αυτού του lock)

- Πηγή βλάβης: Alpha (και Beta όπου ισχύει) · panel εμφανίζει κατάσταση.
- Ηχητικός: buzzer / έξοδος συναγερμού μητρικής · sync με UI μπάρας.
- Ακριβή ελληνικά strings ανά τομέα και λίστα probes ανά detail: επόμενες συνεδρίες EEZ + firmware.
