## Επόμενο βήμα (χρήστης → μετά μαζί)

Ο χρήστης σχεδιάζει στο EEZ (`Othoni_Levita_4`) **μία-μία** τις detail οθόνες:

| Οθόνη | Περιεχόμενο (κατεύθυνση) |
|-------|--------------------------|
| **ΝΕΡΟ** | Αισθητήρες θερμοκρασίας νερού όπως τους σκέφτεται |
| **ΑΝΤΛΙΑ** | Κατάσταση / λειτουργίες HP |
| **ΕΞΟΔΟΙ** | Ρελέ / κυκλοφορητές |
| **ΜΠΟΙΛΕΡ** | Μπόιλερ / διαχωριστής |
| **ΣΥΣΤΗΜΑ** | Γενική υγεία / συναγερμοί τομέα |
| **ΔΙΚΤΥΟ** | Links / Wi‑Fi |

Όταν είναι έτοιμες στο EEZ → επανέρχεται → **πέρασμα στο panel firmware** + **μικρό τεστ λειτουργίας** (όχι ακόμα πλήρες δέσιμο Alpha αν δεν υπάρχει).

Κανόνας συναγερμού: ήδη κλειδωμένος — κόκκινο σε πλαίσιο / slot όταν probe ή στοιχείο δεν δίνει δεδομένα.
